# ابطال العرب - Content Hub & Digital Store

موقع ويب احترافي متعدد اللغات (عربي + ألماني) لصانع المحتوى ihabbob66

## المميزات

✅ **مركز توزيع محتوى** - عرض أفضل الفيديوهات من TikTok
✅ **متجر رقمي** - بيع المنتجات والكورسات والموارد الرقمية
✅ **متعدد اللغات** - دعم كامل للعربية والألمانية
✅ **إعلانات Google AdSense** - مساحات إعلانية متعددة
✅ **تصميم متجاوب** - يعمل على جميع الأجهزة
✅ **تحويل عالي** - دعوات واضحة للإجراء (CTA)
✅ **سهل الاستخدام** - واجهة بديهية وجميلة

## التكنولوجيا

- **React 19** - مكتبة JavaScript
- **Vite** - أداة البناء السريعة
- **Tailwind CSS** - إطار عمل CSS
- **JavaScript** - لغة البرمجة

## البدء

```bash
# تثبيت المتطلبات
pnpm install

# بدء خادم التطوير
pnpm dev

# بناء للإنتاج
pnpm build

# معاينة الإنتاج
pnpm preview
```

## الهيكل

```
src/
├── components/
│   ├── Header.jsx       # رأس الصفحة والقائمة
│   ├── Hero.jsx         # قسم البطل
│   ├── Videos.jsx       # عرض الفيديوهات
│   ├── Products.jsx     # عرض المنتجات
│   ├── AdSpace.jsx      # مساحات الإعلانات
│   ├── Contact.jsx      # نموذج التواصل
│   └── Footer.jsx       # تذييل الصفحة
├── App.jsx              # المكون الرئيسي
├── main.jsx             # نقطة الدخول
└── index.css            # الأنماط العامة
```

## التخصيص

### إضافة كود Google AdSense

1. افتح `index.html`
2. استبدل `ca-pub-xxxxxxxxxxxxxxxx` برقم ناشرك الفعلي
3. أضف كود الإعلانات في مكونات `AdSpace.jsx`

### تحديث المنتجات

عدّل مصفوفة `products` في `src/components/Products.jsx`

### تحديث الفيديوهات

عدّل مصفوفة `videos` في `src/components/Videos.jsx`

## الدخل المتوقع

- **من Google AdSense**: 500-1000 دولار/شهر
- **من بيع المنتجات**: 500-1000 دولار/شهر
- **إجمالي**: 500-2000 دولار/شهر
